주소 검색 수거 경로안 분석 지도 사진·배출 안내 관리자

같은 신월1동 자료, 두 가지 보기

필터로 비교할 때는 Leaflet, Python 분석 결과를 보고 지도로 살펴볼 때는 Folium을 선택하세요.

왜 함께 쓰나요? 웹에서 조건을 살펴보는 용도와 Python 분석 결과를 전달하는 용도를 함께 보여줍니다. Folium도 Leaflet 위에서 작동하므로 같은 자료를 두 방식으로 표현합니다. 두 지도를 모두 써야 분석이 완성되는 것은 아닙니다.

이 페이지에서 가능한 일과 두 도구의 차이
  • Leaflet: 생활권 하나를 고르고 여러 자료를 즉시 켜고 끄며 위치 관계를 탐색합니다.
  • Folium: Python이 선택 조건을 넣은 HTML 지도를 만듭니다. 지도 안의 체크·확대·팝업도 사용할 수 있습니다.
  • 공통: 같은 팀 분석 자료와 색·범례를 씁니다. 현재 두 보기의 필터는 별도로 유지되며 자동 동기화하지 않습니다.
  • 도로폭 필터는 도로선 표시 조건입니다. 후보 재선정이나 수거 경로 계산은 실행하지 않습니다.

도구 설명: Leaflet 공식 안내 · Folium 공식 안내

어떻게 보면 되나요?
  1. 6곳/9곳을 바꾸면 거점 마커와 비교 수치가 바뀝니다.
  2. 자료를 체크하면 필지·도로·보호시설 반경을 겹쳐 볼 수 있습니다.
  3. 마커·도로를 클릭하면 이름과 받은 분석 값을 확인합니다.

숫자는 생활권 번호입니다. 6곳 비교에서는 기존 9생활권 색면을 숨깁니다.

출처와 해석 범위

팀 2차 결과(2026-10-20 확인)와 보존된 1차 도로·보호시설 반경 자료를 사용합니다.

보호시설 반경 200m는 분석 가정이며 법정 보호구역 확정 경계가 아닙니다. 도로폭은 등록값으로 실제 유효폭과 다를 수 있습니다.
