## 평가 범위

개인정보 없는 고정 질문 14건을 현재 서비스 함수에 각 1회 전달했다. 사진·비공개 평가 ZIP은 사용하지 않았다. 구현 에이전트가 실제 응답과 검색된 문단·공식 DB·공식 웹을 대조한 초안이며 독립 사람 검수 결과가 아니다. 기존 HTTP 계약 17건·단위 검사 9건과 분모를 합치지 않는다.

- 질문 목적 충족: 11/14 (78.6%), 부분 충족: 3/14 (21.4%). 부분 충족을 정답으로 합산하지 않았다.
- 확인한 응답에서 근거 없는 사실 단정 발견: 0/14. 일반 환각률 0% 또는 모든 질문에서 안전함을 뜻하지 않는다.
- 안내 응답 5건, 확인 요청 9건, 처리 오류 0건. 보류 상태만으로 성공 판정하지 않았다.
- 전체 처리시간 평균 1.629초, 중앙값 1.922초. DB·가드 응답과 외부 모델 응답을 섞은 값이며 모델 속도 비교에 사용하지 않는다.
- 관측된 생성 입력 11,062토큰, 출력 993토큰. 임베딩 사용량과 비용은 측정하지 않았다.

## 발견한 개선점

1. **자료 커버리지 부족(Q10~12):** 과태료·취소/환불·깨진 도자기의 공식 웹 안내가 현재 발췌 DB에는 빠져 있어 답변을 못 했다. 할루시네이션을 피했지만 사용자 질문을 해결하지 못했다.
2. **불필요한 재질문(Q12):** 도자기라고 이미 밝혔는데 품목명을 다시 요청했다. 근거 부족과 사용자 입력 부족을 구분해야 한다.
3. **답변 집중도(Q01~03):** 근거 문단 전체를 설명해 질문과 직접 관련 없는 절차까지 길게 붙는다. 조건은 유지하되 필요한 부분을 먼저 답하는 개선이 가능하다.
4. **가격 한계(Q04):** DB 계산은 맞지만 현행 수수료표 전체를 재검증한 결과가 아니다. 참고값 고지를 유지한다.
