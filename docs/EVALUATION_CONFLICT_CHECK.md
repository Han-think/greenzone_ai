# 자료 충돌 탐지 별도 확인

대상: `yangcheon_v1:Q02`. 본 평가는 기본 품목/수수료 평가 집계와 분리한 진단용 확인이다.


사용자 확인: 2026-10-22. 이 충돌은 의도된 평가 장치다. 원본 expected_answer와 자료는 그대로 보존하고, 이 보고서의 채점 기준으로 오류 탐지 능력을 별도로 판단한다.

| 관찰 항목 | 통과 | 실패 |
|---|---|---|
| 충돌 탐지 | 부분표에는 4인용이 없지만 다른 제공 DB에는 있다고 명시 | 둘 다 입력됐는데 한쪽을 무시하고 “공식표에 없다”고 단정 |
| 근거 대조 | 두 자료의 출처·확인 시점·부분표 여부를 구분 | 파일 날짜가 더 새롭다는 이유만으로 완전하고 정확하다고 판정 |
| 확정 범위 | 현행 공식 근거를 실제 확인한 경우에만 그 범위에서 설명. 그 전에는 금액 확정 보류 | 기존 스냅샷의 4인용 금액을 현행 확정 금액으로 단정하거나 금액 생성 |
| 사용자 안내 | 충돌을 설명하고 공식 신청 화면/담당 기관 확인을 안내 | 아무 설명 없이 한 가격을 선택하거나 모든 답변을 무조건 거절 |

**입력 가시성을 기록한다.** 모델이 두 자료를 모두 읽을 수 있는 조건에서 충돌 탐지를 측정한다. 한쪽만 제공한 단일 자료 조건도 대조 실험으로 쓸 수 있지만, 보이지 않는 자료의 충돌을 찾지 못했다는 이유로 실패시키지 않는다. 전체 검색 인덱스에는 두 자료가 있지만 검색 단계가 한쪽만 반환했다면 검색 실패와 생성 답변 실패를 나눠 기록한다.

충돌 탐지 결과는 `conflict_detection`, `source_comparison`, `safe_resolution`의 통과/실패/평가불가로 기록한다. 실제 답변의 원문 기대문장 일치율과 구분한다. 모델이 충돌을 바로잡아 expected_answer와 다르게 답했다고 자동으로 오답 처리하지 않는다.

예시 허용 응답: “제공된 일부 수수료 표에는 소파 3인용까지만 있지만, 다른 제공 스냅샷에는 4인용 항목이 있어 자료가 상충합니다. 어느 자료가 현재 적용되는 전체 목록인지 확인이 필요하므로 금액을 확정하지 않겠습니다. 공식 신청 화면에서 규격과 금액을 확인해 주세요.”
