# REQ-DA-001 구현 상세·데이터 출처

작성 범위: 이원홍 담당 수요 자료 정리·개발 인계 / 확인일: 2026-10-20

**서비스 소개:** 신월1동의 건물·수요와 도로·후보지 자료를 연결해, 주소 검색으로 제안 배출 거점과 선정 근거를 확인하는 웹 서비스입니다.

## 요구사항 정의서에 넣을 구현 상세

건축HUB 건축물대장과 VWorld 건물 도형을 필지고유번호(PNU)로 결합하고, SGIS 행정동 경계로 신월1동 자료를 추출한다. 주건축물의 주용도·기타용도로 주거·상가·복합을 분류하고 아파트 포함 필지와 기타·분류 보류를 구분한다. 대장 가구 수와 세대 수는 각각 집계한다. 과거 청소권역 배출량은 같은 연도 SGIS 가구·주택 통계를 이용해 조건부 참고량으로 추정한다. 결과를 공통 `building_id`·좌표와 CSV/JSON으로 전달해 주소 검색·지도에 연결한다. **거점별 분산 배정·보행거리 계산은 별도 후속 작업이며 현재 완료 범위에 포함하지 않는다.**

## 분석 방법과 결과

1. **결합·공간 추출:** 주건축물 대장과 건물 도형을 PNU로 결합하고 SGIS 경계 안 대표점을 필지당 1개로 정리한다.
2. **대상 분류:** 관측 **1,738필지** 중 대상 **1,665필지** = 주거 1,155 + 상가 108 + 복합 402. 아파트 포함 20, 기타 44, 분류 보류 9필지는 구분 보관한다.
3. **수요 구분:** 대상의 대장 가구 **3,070**, 대장 세대 **4,112**는 서로 더하지 않는다. 주거 기록에서 양수 세대 수 우선, 없으면 양수 가구 수를 택한 **7,145는 혼합 대리지표**이며 실제 거주 세대 수가 아니다. 주거·복합 4필지는 대리지표 미산정으로 남긴다.
4. **과거 배출량 참고 추정:** `권역 연간 배출량 × 신월1동/권역 가구 비율 × 비아파트 주택 비율`. 가구당 동일 발생·주택 비율 대리·상가 미보정 가정이 있으며 필지별 실측량이 아니다. 12개월이 있는 연도를 사용하고 재활용은 집계 범위 확인 전 추정을 보류한다.

## 산출물·서비스 연결·남은 작업

- **현재 미완:** 후보별 배정·거리·권역·차량 순서. 팀 11후보에 연결할 규격만 준비했다. 팀 그림의 6,853세대 산식이 미제공이므로 7,145와 같은 값으로 취급하지 않는다. 도로·정차·보행 안전 검토는 REQ-DA-002와 합의 후 배정에 반영한다.
