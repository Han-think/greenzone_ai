# 신월1동 그린존 1차 후보군 (greenzone1st)

> 작성 2026-10-19 · 데이터 분석 담당
> 원본 데이터: 건축물대장표제부, 노인장애인보호구역 표준데이터, 전국어린이보호구역표준데이터, 전국주차장정보표준데이터, 전국도시공원정보표준데이터, 서울특별시_양천구_지도, HangJeongDong_ver20260701.geojson

## 1. 한눈에 보기

- 대상: 서울 양천구 **신월1동 경계 안**
- 1차 후보군: **11곳** = 공영주차장 4 + 공공시설 2 + 도로변 공터 5
- 도로변 공터 5곳은 **위성지도로 2차 확인** 완료 (공터로 이용 중 확인)
- 위치 확인: `greenzone1st_map.html`을 브라우저로 열면 실제 지도 위에서 볼 수 있음

## 2. 1차 선정 기준 (3개 모두 합격/불합격)

| # | 기준 | 내용 | 판정 방법 |
|---|---|---|---|
| 1 | **차량 접근성** | 5t 수거트럭이 통행할 수 있을 것. 거점의 도로 폭은 최소 7m 확보 | 양방향 통행 가정. 등록 도로폭 7m 이상이면 인정, 아니면 등록폭과 실폭도로 실측폭 중 작은 값이 7m 이상. 노상주차장은 주차면 2.5m 제외 |
| 2 | **안전성** | 어린이·노인·장애인 보호구역이 아닐 것 | 보호구역 대상시설 반경 **200m 밖**. 어린이공원은 보호구역이 아니어도 아이들 공간이므로 제외 |
| 3 | **부지 확보 가능성** | 공원·공영주차장·공터 등으로 일정 면적 이상의 부지가 확보될 것 | 공영주차장, 구 소유 공공시설(앞마당·주차공간), 도로변 공터(500㎡ 이상 + 접한 도로 12m 이상) |

## 3. 선정 과정

1. 기준 1~3으로 추렸을 때 **15곳**
2. 그중 공원 3곳(곰달래공원·반곡공원·신월공원)은 보호구역은 아니지만 세부 유형이 **어린이공원**이어서, 안전성 기준의 설명력을 위해 제외
3. 같은 도로(곰달래로5길)에 붙은 도로변 공터 2곳 중 면적이 작은 1곳(곰달래로5길 83 인근, 698㎡)을 제외
4. 최종 **11곳**, 도로변 공터는 위성지도로 실제 공터인지 2차 확인

## 5. 2차 기준 (다음 단계)

1차 후보군 11곳 중에서 실제 거점을 고르기 위한 기준입니다. 수치(x)는 팀에서 정할 예정입니다.

| 기준 | 내용 |
|---|---|
| **보행 접근성** | 각 가구에서 거점까지의 거리가 x m 이하 |
| **거점 커버리지** | 거점 1곳당 최소 x 세대를 커버 |
| **거점의 총 개수** | 거점이 많을수록 보행 접근성은 좋아지지만 수거차 편의성은 떨어짐 → 거점 수와 보행 접근성은 트레이드오프 |

필요한 작업: 건물별 세대·가구 수(건축물대장 표제부) 연결 → 가구별 최근접 거점과 도로 거리 계산 → x 값을 바꿔 가며 거점 조합 비교
