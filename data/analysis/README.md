# 신월1동 건물·필지 수요 분석 인계본

REQ-DA-001 / 2026-10-19 / 데이터 정리·리뷰 단계

## 오늘 한 일

프리뷰의 공식 원본을 이용해 신월1동 필지 자료를 다시 집계했다. 아파트를 제외하고 주거·상가·복합용도를 구분했다. 공식 구역별 배출량을 추가 확보하고, 같은 연도 SGIS 가구·아파트 수를 이용한 조건부 추정 예시를 만들었다. 새로운 거점·권역 배정·수거 동선은 계산하지 않았다.

## 먼저 볼 결과

| 항목 | 결과 |
|---|---:|
| 프리뷰에서 확인된 경계 안 필지 | 1,738 |
| 아파트 포함으로 제외 | 20 |
| 분석 대상 | 1,665 |
| 주거 용도만 탐지된 대상 | 1,155 |
| 상가 용도만 탐지된 대상 | 108 |
| 복합용도 대상 | 402 |
| 학교·의료 등 맥락 검토만 하는 필지 | 44 |
| 대장 미연결 등 분류 보류 | 9 |

단위는 **필지**다. 독립 건물 수·세대 수·배출량으로 읽지 않는다. 프리뷰가 확보한 건물 도형·대장 연결 범위이며 신월1동의 모든 필지를 빠짐없이 조사했다고 뜻하지 않는다. 아파트 20곳 중 14곳은 기존 아파트 제외 분류, 6곳은 기존 맥락 분류에 포함돼 있었다. 이번 인계에서는 아파트 20곳을 한 파일로 모아 명확히 제외했다. 필지 대표 건물 점을 경계와 대조했으므로 경계에 걸친 건물의 실제 출입구는 추가 확인 대상이다.

대상 필지의 대장 가구 수(fmlyCnt)는 3,070, 세대 수(hhldCnt)는 4,112다. 두 항목은 합산하지 않는다. 실제 거주 수·주거/상가별 면적·공실을 확인한 수치가 아니다. 특히 상가 주용도 기록에도 가구/세대 값이 있어 주용도별 점검이 필요하다.

## 우선 읽을 분석

[공식 구역별 물량과 세대수 기반 추정](waste_estimation_method.md)에 최신 확보 자료와 계산식을 정리했다. 필지별 배출량 칸은 미산출 상태이며 동 단위 조건부 추정은 별도 CSV로 제공한다.

## 과거 배출량: 무엇까지 확인했나

### 신월1동 인구·가구·주택 API 통계

프리뷰에 설정된 SGIS 키로 공식 API를 직접 호출해 2021·2022·2024년 신월1동 자료를 확보했다. 도커 실행이 필요한 수집이 아니다. 인증키·토큰은 인계 파일에 없다.

| 기준연도 | 인구(명) | 가구(가구) | 주택(호) |
|---|---:|---:|---:|
| 2021 | 20,158 | 9,208 | 6,160 |
| 2022 | 19,878 | 9,304 | 6,248 |
| 2024 | 18,712 | 8,981 | 6,081 |

[SGIS 공식 센서스 API 설명](https://sgis.mods.go.kr/developer/html/newOpenApi/api/dataApi/census.html). 동 전체 총계여서 아파트가 포함돼 있다. 필지 대장 수치와 모집단·시점이 달라 합산하지 않는다. 가구·주택·필지는 각각 다른 단위다. 이 자료는 대상 지역의 규모와 기준연도 비교에 활용하고, 비아파트 배출량 추정에는 같은 계통의 분모를 추가로 확인한다.

### 일반 생활폐기물

[양천구 제1차 탄소중립 녹색성장 기본계획(2025.4)](https://www.pcccr.go.kr/storage/board/base/2025/07/03/BOARD_ATTACH_1751510256077.pdf)의 인쇄 12쪽 / PDF 14쪽 표를 원문 이미지와 대조했다. 2016~2022년 구 전체 일평균 발생량을 별도 CSV에 옮겼다. 2022년 값은 **309.9톤/일**이다. 아파트를 포함한 구 전체 수치이며 신월1동 측정량이 아니다. 구 통계를 신월1동 비아파트에 나눠 넣거나 음식물 통계에 더하지 않았다.

### 음식물폐기물

[공공데이터포털 공식 파일](https://www.data.go.kr/data/15069391/fileData.do)의 기준일은 2026-08-31이고 실제 행은 **2021-01~2026-07의 65개월**이다. 2022-11·12월 행이 없다. 2022년부터 사업장 4개 항목은 미집계라고 포털에 명시돼 있다. 빈칸은 0으로 바꾸지 않았다. 단위는 CSV·포털 정의 모두 명시하지 않아 `not_stated_in_source`로 기록했다. 파일명 기준일과 마지막 발생월은 서로 다르다.

공동주택 열은 아파트와 빌라·다세대가 분리돼 있지 않다. 따라서 아파트 제외를 이유로 공동주택 열 전체를 삭제하지 않았다. 음식물 통계는 참고 분석이며 이번 일반 배출 수요를 대신하지 않는다.

겹치는 과거 파일의 개정값 2셀은 `official_file_revisions.csv`에 기록했다. 최신 공식 파일을 사용하고 예전 원본도 남겼다. 연간 합계는 12개월 값이 모두 있을 때만 계산했다. 부분연도를 정상 연간 합계로 비교하지 않는다.

2020 음식물 동선표는 시간·업체·권역 자료다. 배출 중량이 없어 이번 배출량 계산에는 사용하지 않았다.

## 검토 완료와 남은 일

- 기존 필지 ID 중복, 경계 포함, 대장 재분류, 아파트 혼입, 가구/세대 합계와 프리뷰의 일치 여부를 `analysis_summary.json`과 `review_log.csv`에 남겼다.
- 집계 자료 검토이며 현장 확인 완료를 의미하지 않는다. 건축물 원자료 작성일은 미확인이고 경계는 2025년 자료다.
- 신월1동 비아파트의 과거 계량자료 또는 지역·주거유형·폐기물 계통이 맞는 원단위를 확보해야 **kg/일 추정**을 할 수 있다. 필지별 `waste_kg_per_day`는 빈칸이며 0이 아니다. 동 단위 비아파트 조건부 추정은 별도 파일에 계산했다. 실측값과 구별한다.
- 우선 요청할 자료: 동·월·품목·수거계통별 반입/계량량, 아파트 별도 수거 구분, 대상 가구/인구 또는 영업장 분모, 음식물 파일 단위. 미확보 시 필지·가구/세대 항목을 대리지표로 쓸지 팀에서 결정하고 한계를 표시한다.
- REQ-DA-001 전체의 분산 배정은 후속 작업이다. 이 인계본만으로 거점 선정·안전 승인·배출량 예측을 완료했다고 발표하지 않는다.
- 후속 배정은 `allocation_review_options.md`의 세 안을 비교한다. 기존 6개 조사점을 정답으로 고정하지 않는다. 도로 유효폭과 진입·정차·보행 조건을 확인한 뒤 후보 좌표와 개수를 검토한다.

## 팀원에게 짧게 전달

신월1동 프리뷰 자료에서 아파트를 제외한 1,665필지를 주거 1,155·상가 108·복합 402로 정리했습니다. 과거 일반 생활폐기물과 음식물 발생량은 출처·기간·단위·누락을 구분했습니다. 공식 1구역 물량과 같은 연도 가구·아파트 주택 수를 이용한 신월1동 비아파트 추정 예시를 별도로 만들었습니다. 동일 가구당 발생량 등 가정과 상가 미보정·재활용 제외 조건을 표시했습니다. 이번 인계는 기초 데이터와 리뷰 결과이고, 이후 담당자가 수요 추정과 배정을 이어갈 수 있습니다.

## 이번 팀 폴더 인계에서 달라진 것

파일·폴더는 영어로 통일하고 문서 링크를 맞췄다. CSV·JSON·GeoJSON의 결과 값은 재계산하지 않았다.
원래 인계본의 최상위 파일 전체를 대응시킨 목록은 analysis_package_manifest.json에 있다.
original_delivery_manifest.json은 **당시 인계본의 기록**이며 현재 영문 경로 검사용 목록은 아니다. source_manifest.json은 이전 C 보존본보다 최신인 분석 정본의 출처 검토본을 사용했다.
원문·통계 응답·CSV·표 이미지와 음식물 설명 페이지는 ../raw에 있다. 파일별 연결은 ../data_inventory.csv에서 찾는다.
과거 음식물 동선표는 2020년 자료이며 배출 중량 추정이나 현행 노선으로 사용하지 않는다.
이번 작업은 기존 분석·증거의 인계이며 서버·모델·분석을 실행하지 않았다.
