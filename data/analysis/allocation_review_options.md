# 신월1동 분산 배정 후속 검토안

2026-10-19 / 이번 인계는 기초 데이터 분석. 아래는 도로 자료 확보 후 비교할 설계안이다.

## 먼저 확인할 공통 조건

세 안 모두 같은 안전·부지 조건을 통과한 후보에서 비교한다. 안전 조건을 완화해 이동거리를 줄이지 않는다. 확인되지 않은 조건은 미확인으로 기록하며 실제 운영 후보로 승인하지 않는다.

| 항목 | 필요한 자료와 확인 내용 |
|---|---|
| 차량 진입 | 실제 수거차 크기·중량·회전반경, 일방통행, 진입 제한, 회차·출차, 전선·수목 등 높이 장애 |
| 도로 유효폭 | 도로 경계/도로대장 폭과 현장 통행 가능 폭을 구분. 주차·전봇대·보도·적치물로 줄어든 폭 확인 |
| 정차와 작업 | 차량 정차 후 다른 차량·보행자 통행이 유지되는지, 작업자가 들어갈 공간, 후진·횡단 위험, 정차 시간대 |
| 보행 접근 | 건물 출입구부터 실제 걸어갈 길, 횡단보도·단절·급경사·보행약자 이동과 보호구역 |
| 부지와 관리 | 실제 설치 면적, 소유·사용 동의, 청소·악취 관리 주체, 배출 시간·품목·수거 계약 |
| 배출 수요 | 비아파트 주거·상가를 구분한 과거 배출량 또는 출처를 설명할 수 있는 대리지표. 물량 미확정 시 용량 적합성도 미확인 |

위성/항공사진은 막힘·공간의 1차 확인에 사용한다. 사진만으로 유효폭·회전 가능·주차 상태·차량 안전을 확정하지 않는다. 넓은 도로도 교통량·횡단·정차 제한 때문에 부적합할 수 있다. 차량과 작업 조건이 미정이므로 일률적인 최소 폭 수치를 임의로 정하지 않는다.

## 비교할 세 가지 예시안

| 안 | 공통 조건을 통과한 뒤 우선할 요소 | 함께 확인할 지표 |
|---|---|---|
| A 주민 접근 우선 | 건물에서 가까운 복수 후보로 분산. 일부 건물만 멀리 배정되지 않게 확인 | 평균·P90·최대 보행거리, 장거리 배정 건물 수, 후보별 수요 편중 |
| B 수거 작업공간 우선 | 진입·정차·출차가 확인되고 연속 수거가 가능한 후보 우선 | 주민 이동거리, 정차 작업 가능 여부, 후진·회차 횟수, 도로망 이동거리 |
| C 부담 균형 | 주민 이동거리와 수거 이동·정차 부담을 나란히 비교 | A·B와 동일 지표, 수요 편중, 관리·부지 조건, 추가 조사 건수 |

후보 개수·간격·차량 이동 순서는 현재 확정하지 않는다. 확인된 후보 수와 수요에 따라 대안별 수를 정한다. 계산된 최단거리와 실제 운행 가능성은 따로 표시한다. 한 숫자로 안전성을 점수화해 확정하지 않는다.

## 다음 담당자에게 필요한 전달물

1. 이번 인계의 필지 ID·용도·좌표·검토 목록.
2. 도로 구간 ID, 출처·기준일, 명목폭/유효폭, 통행 방향·진입 제한, 현장 확인 여부.
3. 후보별 부지·정차·보행·관리 조건의 확인/부적합/미확인과 사유.
4. 조건 통과 후보를 이용한 A/B/C 비교표와 미배정 이유.

이번 데이터 인계에는 새 후보 좌표·권역·배정표·경로를 넣지 않는다. 기존 프리뷰 6점 역시 이번에 선정·검증한 결과로 사용하지 않는다.
